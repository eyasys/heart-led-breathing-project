# Heart LED Breathing / Roulette PCB Project

## Project Overview
This project is a DIY heart-shaped LED breathing/chasing circuit created for our PCB Design subject.

The design is inspired by existing heart LED solder kits and recreated using a universal PCB board instead of a custom manufactured PCB.

The project uses an LM358N-based analog circuit to generate LED breathing/chasing effects.

---

## Objectives
- Learn PCB layout planning
- Practice soldering
- Understand analog circuits
- Learn troubleshooting techniques
- Build a working LED heart project

---

## Components Used
- LM358N IC
- LEDs
- Resistors
- Capacitors
- Potentiometer
- Transistor
- Universal PCB Board
